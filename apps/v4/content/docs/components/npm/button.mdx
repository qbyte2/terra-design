## Usage

```tsx
import { Button } from "@terra-design/react"
```

```tsx
<Button variant="outline">Button</Button>
```

## Composition

Terra Design uses Base UI internally. Use the `render` prop when composing the button with another button component.

```tsx
<Button render={<MyButton />} variant="secondary">
  Continue
</Button>
```

Links should keep link semantics. Apply `buttonVariants` to an anchor instead of rendering an anchor through `Button`.

```tsx
import { buttonVariants } from "@terra-design/react"

;<a className={buttonVariants({ variant: "link" })} href="/docs">
  Documentation
</a>
```

## API Reference

| Prop       | Type                                                                                 | Default     |
| ---------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant`  | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`     | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `disabled` | `boolean`                                                                            | `false`     |
| `render`   | `ReactElement \| function`                                                           | —           |
