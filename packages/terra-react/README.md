# @terra-design/react

Terra Design components for React, built with Base UI and the Nova visual style.

## Install

```bash
npm install @terra-design/react
```

Import the package stylesheet from your Tailwind CSS v4 global stylesheet:

```css
@import "tailwindcss";
@import "@terra-design/react/styles.css";
```

Then import components from the package:

```tsx
import { Button, Card, CardContent } from "@terra-design/react"
```
